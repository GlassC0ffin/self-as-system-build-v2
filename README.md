# Inverse Decay (v2) — Self as System

## System Rules
* Triangles remain ordered and stable while the cursor moves continuously.
* Pausing movement (velocity under 4px/frame) triggers immediate rotation spin and ember color shifts.

## Controls
* Move mouse rapidly to enforce structural symmetry.
* Hold mouse still to trigger rapid rotational decay.

## v2 Reflection
In v2, I removed the overlay text panel and positional jitter to let canvas math function as the sole communicative element. Setting a strict 4px/frame velocity cutoff forces the system to react aggressively the moment cursor movement stops. Without jitter obscuring the shapes, the escalation from structural order to rotational chaos is immediately legible, turning user stillness into a direct catalyst for systemic breakdown.
